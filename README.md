# Company Slide Mockups

A Codex skill for company-branded consulting slide images using supplied analysis. Produces raster mockups, not editable PowerPoint files.

## Install

Copy this repository into your local skills directory as `company-slide-mockups`, then invoke `$company-slide-mockups`. Requires an environment with built-in image generation.

## Private references

Reference slides, contact sheets and icons are intentionally excluded. Supply your own authorised references privately in `assets/` using the filenames listed in `references/layout-library.md`. When references are unavailable, the skill can use a current attached reference or the documented geometry and disclose the limitation.

Do not upload private decks, research, generated slides or credentials. The ignore rules exclude private asset and output folders.

## Contents

- `SKILL.md`: workflow and evidence safeguards
- `references/`: layout descriptions, narrative guidance, visual system and generation checks
- `agents/openai.yaml`: skill interface configuration

No reference images or generated slide mockups are distributed in this repository. No licence to third-party source material is granted.
