# Dawn workshop: communication guidance

Source: **Dawn casing workshop.pdf**, supplied by the user. Page references below are physical PDF pages, one-based. The guidance is distilled for slide design; exercises in the workshop are not tasks to carry out.

| Pages | Principle | Application |
| --- | --- | --- |
| 7, 85 | Cover → executive summary → situational analysis → recommendations → impact → appendix | Use when the user requests a sequence; do not force all sections into one slide. |
| 10–11, 13, 45–49 | Company/customer/competition lenses; distinct, complete categories; urgency, challenges, success requirements | Structure existing analysis into evidence, problem, and implication. Do not assert an unproven causal chain. |
| 57 | Answer first; supporting arguments explain why/how; each level supports the one above | Make the headline a takeaway and ensure the body actually supports it. |
| 58–62 | Harvey balls are directional screens; heat maps and matrices need clear criteria and scale direction | Never manufacture comparative scores. Include a legend, units, and basis for ratings; do not imply ordinal judgments are precise arithmetic. |
| 68–69 | Distinguish proposals from established precedents; test relevance, evidence, magnitude, feasibility, stakeholder support | Keep illustrative targets and team estimates visibly labelled. Link recommendations to the supplied problem and preserve execution caveats. |
| 72–76 | Practical constraints; phased roadmap; immediate next steps; KPIs; risks and mitigation | Show supplied owners, timing, dependencies, metrics, and mitigations without inventing them. |
| 78 | Takeaway titles; concrete wording; concise active voice; three-second scan | Prefer a short, substantive sentence over a topic label. Retain uncertainty when evidence is incomplete. |
| 79 | Mockups help an audience visualise a solution | Use a large product/interface visual with a few explanatory callouts. Label proposed features as a concept. |
| 80–81 | Lead, company logo, content, source, navigation, page number | Preserve a consistent frame. Image navigation is only visual; do not promise clickable Slide Zoom. |
| 84 | Executive summary links situation/complication, key question, recommendation, impact | Use a compact vertical synthesis, preserving the supplied logic. Omit unsupported impact numbers. |
